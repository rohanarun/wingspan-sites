# Wing Span site publishing

The publisher that hosts the interactive websites generated by the **AEO/SEO agent** for
[Wing Span](https://gotwingspan.com/). It accepts HTML and static assets and stores them
transactionally in SQLite on a Render persistent disk, so restarting or redeploying the service
never loses a publication.

This is a deployment of the same publisher used by KreatorAI, with a Wing Span landing page.

## API

- `POST /api/sites`: publish HTML and optional assets, with `Authorization: Bearer <publishing key>`.
- `GET /api/sites/{slug}`: authenticated publication receipt.
- `GET /sites/{slug}/`: public website; relative assets are served under the same path.
- `GET /openapi.json`: OpenAPI schema; `/docs`: interactive API reference.
- `GET /published-sitemap.xml`: complete inventory of indexable published sites.
- `GET /health`: liveness plus storage check.

Example (read the key from a private environment variable):

```sh
curl "$WEBSITE_HOSTING_ENDPOINT" \
  -H "Authorization: Bearer $WEBSITE_HOSTING_API_KEY" \
  -H 'Content-Type: application/json' \
  --data-binary @site.json
```

`site.json`:

```json
{
  "slug": "recovery-load-tracker",
  "task_token": "stable-job-id",
  "title": "Recovery load tracker",
  "html": "<!doctype html><html><head><title>Recovery load tracker</title></head><body><h1>Recovery load tracker</h1></body></html>"
}
```

The response includes `url`, `canonical_url`, `revision`, `sha256`, and social-card readiness. An
exact retry returns the current receipt without overwriting newer content. A different task cannot
claim an occupied slug. Changed content requires the previous `expected_revision`. Upload assets as
`{"path/to/file.js":{"content":"...","encoding":"utf-8"}}` or base64 for binary data. Upload a
1200x630 PNG and set `social_card_path` for a preview-ready response. The hosting transport aligns
canonical/OG URLs with `PUBLIC_BASE_URL`; source content and interactions remain model-authored.

## Wiring into the AEO/SEO agent

In the AEO/SEO agent power settings:

- **Primary custom hosting domain (optional)** = `https://wingspan-sites.onrender.com/api/sites`
- **Hosting API key** = the value of `PUBLISH_API_KEY` for this service

Leave the endpoint blank to keep the default GetSupers host. A configured-host error fails closed and
never falls back to a different domain. Sites rotate sequentially: GetSupers, then this host, then
each additional domain configured below it.

### Custom domain

When the subdomain is live, add it to Render as a custom domain for this service, then set
`PUBLIC_BASE_URL` to the new origin **and** update the power's endpoint to match, in the same step.
The two must agree, because the publisher stamps canonical and Open Graph URLs from
`PUBLIC_BASE_URL` while the agent posts to the configured endpoint.

## Run locally

```sh
pip install -r requirements.txt
PUBLISH_API_KEY=local-key PUBLIC_BASE_URL=http://localhost:8000 \
  uvicorn publisher:create_app --factory --host 0.0.0.0 --port 8000
```

Run the tests with `pytest tests`.

Writes require the bearer secret and have an 8 MiB request/decoded-size limit. HTML is limited to
600,000 characters. Slug collisions, stale revisions, invalid asset paths, and missing or
non-1200x630 card assets are rejected. `noindex` pages are published but excluded from the sitemap.
Browser cookies and cross-origin credential access are not used. Keep publishing keys out of public
pages, source control, and model prompts.
